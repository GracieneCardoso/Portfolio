# PROJETO 7 - GLYCO TRACK

![Abertura do projeto](imgProj7.png)


🎯 PROBLEMA DE NEGÓCIO:

Neste projeto foi trabalhado atividades de engenharia de atributos em um  cenário onde a precisão é requisito mandatório: dados médicos.

O projeto é bem completo e abrange atividades de todo o processo de análise de dados.

Como Analista de Dados da empresa (hospital, clínica ou operadora de plano de saúde), o trabalho foi identificar os pacientes diabéticos de alto risco por meio de estratificação de risco de  registros  médicos  eletrônicos.  Foi usado  registros  eletrônicos  de  dados  médicos,  como resultados dos exames, nível de insulina, diagnóstico de outras doenças, etc...

A proposta é identificar as readmissões. Readmissões indicam que o primeiro atendimento do paciente não foi feito com qualidade.

Todas as escolhas foram justificadas durante o desenvolvimento do projeto. E ao final, o resultado foi entregue através de diversos gráficos.

Os EUA mantêm um programa constante de redução de readmissão de pacientes. A referência abaixo foi utilizada para entendimento da demanda.

Hospital Readmissions Reduction Program (HRRP)
https://www.cms.gov/Medicare/Quality-Initiatives-Patient-Assessment-Instruments/ValueBased-Programs/HRRP/Hospital-Readmission-Reduction-Program

The top 10 causes of death
https://www.who.int/news-room/fact-sheets/detail/the-top-10-causes-of-death

Associação Americana de Diabetes
https://www.diabetes.org/
