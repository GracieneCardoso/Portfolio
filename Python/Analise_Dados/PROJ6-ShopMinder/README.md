# PROJETO 6 - SHOP MINDER

![Abertura do projeto](imgProj6.png)


🎯 PROBLEMA DE NEGÓCIO:

Neste projeto vamos analisar dados reais, disponíveis publicamente, sobre transações
comerciais em uma rede de varejo. Nosso trabalho será aplicar a técnica de MBA (Market Basket
Analysis) e entregar à gerência a relação de produtos mais comuns nas cestas de compras dos
clientes. Para este projeto usaremos dados disponíveis no link abaixo:

---
🌐 FONTES:
