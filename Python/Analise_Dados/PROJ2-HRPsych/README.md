# PROJETO 2 - HR PSYCH

![Abertura do projeto](imgProj2.png)


🎯 PROBLEMA DE NEGÓCIO:

A empresa aplicou um teste psicotécnico a todos os funcionários e coletou dados sobre idade,
gênero, escolaridade e salário. O objetivo é pré-processar os dados para análise. Como esperado,
os dados apresentam problemas que precisam ser detectados e resolvidos.

Para este projeto temos um dataset com dados de funcionários de uma empresa fictícia.

Os dados usados são fictícios, mas as variáveis representam informação real para o
problema de negócio.
