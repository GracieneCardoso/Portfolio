# PROJETO 3 - CLEAN PREDICT

![Abertura do projeto](imgProj3.png)


🎯 PROBLEMA DE NEGÓCIO:

Neste projeto vamos explorar diversas estratégias de limpeza de dados de uma empresa
de segurança na área de telecomunicações.

A empresa possui registros históricos em um volume de dados de 150 mil registros. Os
dados serão usados para modelagem preditiva, mas antes precisamos realizar um trabalho de
limpeza pois os dados possuem diversos problemas.

Daremos ênfase ao tratamento de valores ausentes, ajuste dos tipos de dados e
tratamento de outliers. Ao final vamos gerar um novo arquivo csv com os dados limpos. Esse é o
entregável deste projeto.

Usamos como fonte de dados o dataset disponível no link abaixo. O dataset foi ajustado
para este projeto e será fornecido a você junto com os scripts e demais arquivos do projeto.
