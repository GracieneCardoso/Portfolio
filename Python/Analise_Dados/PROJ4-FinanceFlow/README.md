# PROJETO 4 - FINANCE FLOW

![Abertura do projeto](imgProj4.png)


🎯 PROBLEMA DE NEGÓCIO:

Neste projeto vamos trabalhar com dados de Contabilidade, realizar análise exploratória
antes e depois da limpeza dos dados, realizar tratamento de valores ausentes com diferentes
técnicas, tratar outliers e então daremos ênfase na interpretação de gráficos estatísticos. Quanto
mais você praticar, mais você aprende. Não há outro caminho para o aprendizado.

O objetivo neste projeto é detectar eventuais problemas nos dados, resolvê-los e então
analisar o comportamento de algumas variáveis, o que faremos interpretando os gráficos.

Os dados são fictícios, mas a definição das variáveis representa informação real da área
de Contabilidade.
